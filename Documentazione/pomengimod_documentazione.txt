1. BASE DEL PROGETTO
------------------------------------------------------------
- Loader: NeoForge 21.1.259 per Minecraft 1.21.1 (Java 21)
- Mod ID: pomengimod
- Nome: PomengiMod
- Group ID / package base: net.chickenhole.pomengimod
- Repository: https://github.com/tommasofulgosi/pomengi.git (PRIVATA, branch attivo: mouhamed-dev)
- Il file neoforge.mods.toml sta in src/main/templates/META-INF/

2. STRUTTURA DEI PACKAGE (src/main/java/net/chickenhole/pomengimod/)
------------------------------------------------------------
- PomengiMod.java ................ entry point @Mod
- config/Config.java ............. tutti i parametri
- core/ModTiers.java .............. materiale custom pomengite
- core/registry/ ................. solo registrazioni:
    ModBlocks.java (blocchi), ModItems.java (oggetti),
    ModCreativeTabs.java (tab creativa + icona custom), ModEntities.java (vuoto, pronto),
    ModSounds.java (suoni), ModEffects.java (effetti)
- content/block/ ................. classi dei blocchi (PomengiteBlock.java, PomengiteBlock_Variante.java)
- content/item/ .................. classi degli oggetti (PomengiteSwordItem.java, PomengiMineral.java)
- content/effect/ ................ classi degli effetti (PomengiteEffect.java)
- content/entity/ ................ (vuoto, futuro mob/boss)
- client/ ........................ PomengiModClient + model/, renderer/, gui/
- worldgen/ ...................... (vuoto, future strutture)
- integration/ ................... (vuoto, future mod esterne)

3. RISORSE (src/main/resources/)
------------------------------------------------------------
- assets/pomengimod/blockstates/ .. un json per blocco
- assets/pomengimod/models/block/ . modelli cubici
- assets/pomengimod/models/item/ .. modelli oggetto (blocchi: parent al modello blocco;
                                   spada: parent minecraft:item/handheld)
- assets/pomengimod/textures/block/ e .../item/ .../mob_effect/ .../entity/ .../gui/
- assets/pomengimod/sounds/ + sounds.json
- assets/pomengimod/lang/ ........ en_us.json + it_it.json
- data/pomengimod/loot_tables/blocks/ .../entities/ .../chests/
- data/pomengimod/recipe/ ....... ricette di crafting (NOTA: la cartella DEVE chiamarsi recipe al singolare)
- data/pomengimod/advancements/, structure/*.nbt, worldgen/{structure,structure_set,template_pool}/

4. BLOCCHI DI POMENGITE
------------------------------------------------------------
A) Blocco di Pomengite (id: blocco_di_pomengite)
   - Classe: content/block/PomengiteBlock.java
   - Modello: cube_bottom_top con 3 texture (top, side, bottom)
   - Comportamento: 5% probabilita a passo -> suono + messaggio in action bar.

B) Blocco di Pomengite Variante (id: blocco_di_pomengite_variante)
   - Classe: content/block/PomengiteBlock_Variante.java
   - Modello: cube_all (tutte le facce uguali)
   - Texture: textures/block/blocco_di_pomengite_variante.png (16x16)
   - Registrazione: ModBlocks + ModItems (BlockItem registrato)
   - Nomi: "Variant Pomengite Block" (en) / "Blocco di Pomengite Variante" (it)

5. MINERALE DI POMENGI (id: pomengi_mineral)
------------------------------------------------------------
- Classe: content/item/PomengiMineral.java (estende Item standard)
- Texture: textures/item/pomengi_mineral.png (16x16)
- Registrazione: ModItems.POMENGI_MINERAL
- Modello: minecraft:item/generated -> layer0: pomengimod:item/pomengi_mineral
- Nomi: "Pomengi Mineral" (en) / "Minerale di Pomengi" (it)
- Utilizzo: Oggetto grezzo/gemma impiegato come ingrediente nelle ricette di crafting.

6. EFFETTI DI STATO E TAB CREATIVA
------------------------------------------------------------
- Icona MobEffect: textures/mob_effect/pomengite.png
  (Associata automaticamente all'effetto Pomengite quando attivo nel gioco o inventario)
- ModCreativeTabs: configurata con icona custom (ItemStack del Blocco di Pomengite)
  Mostra tutti gli item e i blocchi del progetto nella scheda dedicata.

7. RICETTE DI CRAFTING (data/pomengimod/recipe/)
------------------------------------------------------------
- Spada di Minerale Pomengiato (id file: pomengi_sword.json):
  - Tipo: minecraft:crafting_shaped
  - Pattern: 2x Minerale di Pomengi ("X") in colonna + 1x Bastoncino ("#") in basso
  - Risultato: 1x pomengimod:spada_di_minerale_pomengiato
  - NOTA ARCHITETTURALE: La cartella delle ricette in NeoForge 1.21.1 si chiama rigorosamente `recipe` (senza "s").

8. COMANDI UTILI
------------------------------------------------------------
- .\gradlew runClient ............ avvia Minecraft con la mod
- F3 + T (in gioco) .............. ricarica al volo ricette e asset JSON senza riavviare
- /give @p pomengimod:pomengi_mineral
- /give @p pomengimod:blocco_di_pomengite_variante
- /give @p pomengimod:spada_di_minerale_pomengiato
